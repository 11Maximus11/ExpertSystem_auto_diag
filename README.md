# ИИдеал Авто • Интеллектуальная система автодиагностики (LeCodes48)

Полностью автономное мобильное приложение автодиагностики **«ИИдеал Авто»**, созданное на платформе **le.codes SDK (`2.14.9`)** без веб-сайта и без обязательной регистрации.

- **Дата сборки:** `2026-11-28`
- **Платформа:** `le.codes` (`aideal-auto`, id `328pydjv`) • Android Native (`com.mmcco.aidealauto`), Web Emulator, Desktop

---

## Ключевая архитектура

1. **Единый конвейер ИИ: Локальный RAG -> Встроенный онлайн ИИ `le.codes`**
   - **Локальный Hybrid RAG на устройстве** ([`src/rag/HybridRagEngine.ts`](src/rag/HybridRagEngine.ts)): мгновенный `O(1)` поиск по **12 141** коду неисправности OBD-II (`P/C/B/U`), эталонной телеметрии (`36` профилей PID) и русско-английскому стеммеру + BM25 + символьным 3-граммам (`kb_tier1.json`, `kb_external.json`).
   - **Главная онлайн-LLM** ([`expert.server.ts`](expert.server.ts)): встроенный ИИ платформы `le.codes` (`ai.send<LlmDiagnosticPayload>`) синтезирует структурированные причины, пошаговые регламенты проверки, оценку рисков и анализирует **до 5 фотографий** (`diagnoseWithPhotos`) + **голосовые сообщения (ГС)** и **акустику ДВС**.
   - **Аварийная отказоустойчивость**: при полном отсутствии сети используется встроенный локальный детерминированный синтезатор вердиктов без падений приложения.
2. **Полное хранение на устройстве (без регистрации)**
   - Все проекты, сессии, переписки, чеклисты ремонта, междиалоговая память и профиль авто сохраняются локально ([`src/storage/LocalDatabase.ts`](src/storage/LocalDatabase.ts)).
   - При первом запуске и в Настройках выводится явное предупреждение об удалении локальных данных при деинсталляции приложения, а также работает полный **экспорт/импорт резервных копий (JSON)** и генерация графических **бланков заказ-нарядов (PNG)** через `Canvas.toFile()` + `share()`.
3. **Мультимодальный AR / VR HUD и смарт-очки**
   - Единый оверлей [`createArHudOverlay`](src/ui/components.ts) в **оптическом AR-режиме** (прозрачный фон `#000000` для RayNeo / XREAL / Rokid) и **VR-режиме** (живой полноэкранный видеопоток камеры), плюс нативный мост внешнего дисплея ([`src/ar/ExternalDisplayBridge.ts`](src/ar/ExternalDisplayBridge.ts), Android [`ARHudPresentation.kt`](android/app/src/main/java/com/mmcco/aidealauto/ARHudPresentation.kt)).
   - Съемка фото камерой (`UICameraNode` / галерея), фонарик подсветки моторного отсека (`Torch`), запись и распознавание ГС (`SpeechRecognizer` + `AudioRecorder`) во всех режимах отправляются напрямую в онлайн-модель `le.codes`.

## 5 экранов приложения

1. **Диагноз** (`DiagnosticsScreen.ts`): ИИ-чат с прикреплением до 5 фото, логов (`.txt/.csv/.log/.json/.pdf`), голосовых сообщений (ГС), акустики ДВС, снимков OBD-II и быстрых DTC-пресетов.
2. **Чеклист и Словарь DTC** (`DtcDictionaryScreen.ts`): интерактивные пошаговые чеклисты ремонта, подбор инвентаря, генерация заказ-наряда и быстрый поиск по всем **12 141** коду OBD-II.
3. **OBD-2 Сканер** (`ObdScannerScreen.ts`): подключение по Web Bluetooth / USB Serial к ELM327 (`AT`-терминал, Mode `01`/`03`/`04`/`09 02`) + **4 встроенных демо-сценария ЭБУ** для проверки жюри без автомобиля.
4. **Сессии** (`SessionsHistoryScreen.ts`): локальное управление проектами автомобилей, закрепление, теги, поиск и редактируемая память сессий.
5. **Настройки** (`SettingsScreen.ts`): переключатель Dark/Light темы, управление междиалоговой памятью, бэкап/восстановление JSON и инженерное меню.

## Команды разработки и проверки

```powershell
# Проверка типов TypeScript и сборка бандла
npm run compile

# Автотест пользовательских сценариев
npx lecodes test

# Запуск веб-эмулятора
npm run web

# Отправка и публикация в le.codes
npx lecodes push --publish -m "ИИдеал Авто v1.0.0 (LeCodes48)"
```
