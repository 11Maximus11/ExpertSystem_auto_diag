# ИИдеал-Авто • Нативное Android & Web приложение на базе le.codes

100% нативный клиент экспертной системы автодиагностики **«ИИдеал-Авто»**, построенный на базе фреймворка и SDK [le.codes](https://le.codes/ru/docs).

Приложение полностью переработано: вместо встроенного WebView веб-сайта весь интерфейс реализован на **нативных компонентах `le.codes`** (`UIScreen`, `UITabs`, `UIColumn`, `UIRow`, `UIModal`, `UIButton`, `UIInput`, `signals`), с прямым аппаратным пробросом датчиков **OBD-II (ELM327 BLE/Serial/USB)** и интеграцией с бэкендом **Django REST API**.

---

## Архитектура: Что изменилось

1. **100% Нативный UI на le.codes (без внешнего WebView)**:
   - **5 нативных экранов (`UITabs`)**:
     - `diagnostics`: **ИИ-Диагностика** — интерактивный чат с ИИ-экспертом (AirLLM Google Gemma 4 12B + Vulkan + RAG), чекбоксы задач ремонта, прикрепление телеметрии ЭБУ.
     - `obd`: **Приборы OBD-II** — живые цифровые датчики (RPM, Скорость, Температура ОЖ, Напряжение АКБ, Нагрузка, Дроссель), считывание и сброс кодов DTC (Mode 03 / Mode 04), консоль AT-команд.
     - `dtc`: **Справочник DTC** — оффлайн-каталог кодов неисправностей с локальным кэшированием (Cache API + LocalStorage).
     - `history`: **Сессии** — журнал ранее проведённых диагностик с сохранением параметров.
     - `settings`: **Настройки & Инженерное меню** — выбор темы/языка, очистка кэша, диагностика аппаратных интерфейсов (Web Bluetooth / Serial).

2. **Скрытое Инженерное Меню (Dev Mode)**:
   - Доступно через **7 быстрых кликов** по бейджу версии внизу экрана «Настройки» или по кнопке `⚙ Инж. меню` в шапках экранов.
   - Позволяет на лету менять IP-адрес и порт тестового стенда (Django REST API).
   - Пресеты:
     - `10.0.2.2:8000` — Android Emulator (Visual Studio .NET SDK / AVD).
     - `localhost:8000` — локальный запуск.
     - `192.168.1.100:8000` — отладка по Wi-Fi на реальном смартфоне.
     - `/` — относительный путь для веб-версии.
   - Встроенный инструмент **Ping-теста**: отправляет GET-запрос к API и замеряет сетевую задержку в миллисекундах (`✓ Связь есть! HTTP 200, 14 мс`).
   - Автоматическое сохранение адреса в постоянную память устройства через `signal(...).stored("pwa_server_url")`.

3. **Аппаратный проброс OBD-II (ELM327)**:
   - **Web Bluetooth API**: прямое подключение к BLE-сканерам (Viecar, vLinker, OBDLink CX).
   - **Web Serial API**: подключение проводных USB/COM сканеров (FTDI, CH340, CP2102).
   - **Демо-симулятор ЭБУ**: режим автономной отладки с реалистичной физикой холостого хода, разгона, прогрева и ошибок DTC (P0300, P0171, C0050).
   - Выдвижной мини-HUD бар с быстрыми показателями телеметрии над всеми экранами.

4. **Интеллектуальное кэширование**:
   - Двухуровневое кэширование через `CacheStorage` + `LocalStorage`.
   - Мгновенный поиск кодов DTC без задержек и интернета.

## Сборка APK

Готовый отладочный APK-файл скомпилирован и находится по пути:
```
lecodes_webapp/android/app/build/outputs/apk/debug/app-debug.apk
```

### Команды пересборки при изменении кода:

1. **Синхронизация бандла TypeScript в Android-ассеты**:
   ```powershell
   cd lecodes_webapp
   npx lecodes-cli app sync android
   ```

2. **Компиляция APK через Gradle**:
   ```powershell
   cd android
   .\gradlew.bat assembleDebug --no-daemon
   ```

## Полное руководство по отладке

### Вариант 1: Быстрая отладка на компьютере (Hot Reload)

Для мгновенной проверки интерфейса и логики без запуска эмулятора:

- **В браузере**:
  ```powershell
  cd lecodes_webapp
  npx lecodes-cli web dev
  ```
  Откроется на `http://localhost:3000` с поддержкой горячей перезагрузки при сохранении файлов.

- **В нативном десктопном окне (Electron/Desktop)**:
  ```powershell
  cd lecodes_webapp
  npx lecodes-cli dev --desktop
  ```

---

### Вариант 2: Отладка в эмуляторе Visual Studio .NET Android SDK / AVD

1. **Запустите Django-сервер (хост)**:
   В корневой папке проекта:
   ```powershell
   .\.venv\Scripts\Activate.ps1
   python manage.py runserver 0.0.0.0:8000
   ```
   > **Важно**: указывайте `0.0.0.0:8000`, чтобы сервер принимал входящие подключения от виртуальной сети эмулятора!

2. **Запустите эмулятор в Visual Studio**:
   - В Visual Studio: меню `Tools` → `Android` → `Android Device Manager` → выберите ваше виртуальное устройство и нажмите `Start`.
   - Проверьте доступность устройства через ADB:
     ```powershell
     & "C:\android_sdk\platform-tools\adb.exe" devices
     ```
     Должно отобразиться устройство вида `emulator-5554   device`.

3. **Установите APK в эмулятор**:
   ```powershell
   & "C:\android_sdk\platform-tools\adb.exe" install -r "d:\GDrive\Документы\Visual Studio 2022\ExpertSystem_auto_diag\lecodes_webapp\android\app\build\outputs\apk\debug\app-debug.apk"
   ```

4. **Запустите приложение**:
   ```powershell
   & "C:\android_sdk\platform-tools\adb.exe" shell am start -n com.mmcco.aidealauto/.MainActivity
   ```

5. **Просмотр логов в реальном времени (Logcat)**:
   ```powershell
   & "C:\android_sdk\platform-tools\adb.exe" logcat -s LeCodes:V AIdealMainActivity:V chromium:V
   ```
   Все логи `console.log()` из TypeScript-кода `le.codes` и нативного движка выводятся в тег `LeCodes`.

6. **Проверка связи в приложении**:
   - В приложении перейдите во вкладку **«Настройки»**.
   - Нажмите **10 раз** по плашке версии приложения (`Экспертная система автодиагностики`) для открытия скрытого **Инженерного меню (Dev Mode)**.
   - Убедитесь, что установлен адрес `http://localhost:8000` (при пробросе `adb reverse tcp:8000 tcp:8000`) или `http://10.0.2.2:8000` (шлюз Android-эмулятора к ПК).
   - Нажмите **«Ping»** — в строке статуса отобразится время отклика сервера в миллисекундах.

### Вариант 3: Отладка на реальном Android-смартфоне (USB / Wi-Fi)

1. **Подключение по USB**:
   - Включите на телефоне режим разработчика и **Отладку по USB**.
   - Подключите телефон к компьютеру кабелем.
   - Установите APK:
     ```powershell
     & "C:\android_sdk\platform-tools\adb.exe" install -r "d:\GDrive\Документы\Visual Studio 2022\ExpertSystem_auto_diag\lecodes_webapp\android\app\build\outputs\apk\debug\app-debug.apk"
     ```

2. **Связь с сервером по Wi-Fi**:
   - Убедитесь, что компьютер и телефон подключены к одной Wi-Fi сети.
   - Узнайте IP-адрес компьютера: `ipconfig` (например, `192.168.1.55`).
   - В приложении откройте Инженерное меню и введите: `http://192.168.1.55:8000`.
   - Нажмите **«Сохранить и применить»**.
   - Теперь приложение на телефоне обращается к Django API на вашем ПК, а встроенный Bluetooth LE ищет реальные адаптеры ELM327 в автомобиле!
